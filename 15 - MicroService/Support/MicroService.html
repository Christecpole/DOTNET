--- ## Microsoft.Extensions.ServiceDiscovery **Microsoft.Extensions.ServiceDiscovery** est la solution native de Microsoft pour .NET 8+ offrant une abstraction unifiée pour le Service Discovery: ```csharp // Installation du package // dotnet add package Microsoft.Extensions.ServiceDiscovery // Program.cs - Configuration du Service Discovery builder.Services.AddServiceDiscovery(); // Ajout du provider de configuration (par défaut ou personnalisé) builder.Services.ConfigureHttpClientDefaults(http => { http.AddServiceDiscovery(); }); ``` --- ## Configuration des endpoints Les endpoints des services peuvent être configurés dans **appsettings.json**: ```json { "Services": { "AuthService": { "http": [ "http://localhost:5002", "http://localhost:5003" ], "https": [ "https://localhost:7002" ] }, "ProductService": { "http": ["http://localhost:5004"] } } } ``` Ou via des variables d'environnement: ```bash Services__AuthService__http__0=http://localhost:5002 Services__AuthService__http__1=http://localhost:5003 ``` --- ## Utilisation avec HttpClient Une fois configuré, le Service Discovery est automatiquement intégré avec HttpClient: --- ```csharp public class UserService { private readonly HttpClient _httpClient; public UserService(IHttpClientFactory httpClientFactory) { // Utiliser le nom du service au lieu d'une URL fixe _httpClient = httpClientFactory.CreateClient(); } public async Task<AuthResponse> CheckAuthorizationAsync(Guid userId) { // Le nom "http://authservice" sera résolu automatiquement var response = await _httpClient.GetAsync( $"http://authservice/api/v1/auth/{userId}"); if (response.IsSuccessStatusCode) { return await response.Content .ReadFromJsonAsync<AuthResponse>(); } return null; } } ``` --- ## Configuration par service Pour configurer spécifiquement un HttpClient avec Service Discovery: --- ```csharp // Program.cs builder.Services.AddHttpClient<IAuthService, AuthService>(client => { client.BaseAddress = new Uri("http://authservice"); client.Timeout = TimeSpan.FromSeconds(30); }) .AddServiceDiscovery(); // Active le Service Discovery pour ce client builder.Services.AddHttpClient<IProductService, ProductService>(client => { client.BaseAddress = new Uri("http://productservice"); }) .AddServiceDiscovery(); ``` --- ## Providers de Service Discovery Microsoft.Extensions.ServiceDiscovery supporte plusieurs providers: **Configuration (par défaut)** - Via appsettings.json ou variables d'environnement **DNS** - Résolution via DNS SRV records **Consul** - Avec le package additionnel: ```csharp // dotnet add package Microsoft.Extensions.ServiceDiscovery.Consul builder.Services.AddServiceDiscovery() .AddConsulServiceEndpointProvider(); ``` **Kubernetes** - Détection automatique des services K8s **YARP** - Intégration native avec YARP pour l'API Gateway
